# 🗺️ QuickNote Public Product Roadmap

Welcome to the public roadmap for **QuickNote (随身记)**.  
We build in public and prioritize features based on developer community feedback and GitHub Stars ⭐️.

---

## 🟢 v0.1.0 — Foundation & Production Launch (Current)
- [x] **Rust + Tauri Core**: Lightweight ~25MB memory footprint, blazing startup under 100ms.
- [x] **Global Hotkey Daemon**: System-wide `Ctrl+Shift+Q` listener with zero-stealing focus dismissal.
- [x] **Local SQLite Engine**: Fast WAL-mode database with FTS5 instant full-text search.
- [x] **Floating Acrylic Pin Card**: Keep temporary credentials, regex, or query templates pinned on top.
- [x] **DeepSeek-V4.1 AI Integration**: Dual-track engine supporting official Cloudflare proxy + perpetual BYOK mode.
- [x] **Offline Ed25519 Licensing**: Pure mathematical signature verification for Lifetime Pro.
- [x] **Official Cloudflare Pages Landing Page**: High-performance CDN showcase at `quicknote-official.pages.dev`.

---

## 🟡 v0.2.0 — Power User & Snippet Expansion (Q1 2027)
- [ ] **Clipboard History Listener**: Option to capture recent clipboard items with sensitive data auto-masking.
- [ ] **Local Ollama & vLLM Discovery**: Automatically probe `localhost:11434` to enable zero-config local private AI models.
- [ ] **Syntax Highlighting & Code Sandboxing**: Built-in Monaco / Prism code editor with one-click copy and format.
- [ ] **Global Quick Math & Unit Conversion**: Type inline formulas like `1440 / 60` or `0x7F in dec` and evaluate on the fly.
- [ ] **Custom Shortcut Rebinding**: Support custom global shortcuts beyond `Ctrl+Shift+Q`.

---

## 🟣 v0.3.0 — Workspaces & Community Ecosystem (Q2 2027)
- [ ] **Prompt Template Marketplace**: Community-curated System Prompts (Refactoring, SQL Optimizer, Unit Test Generator).
- [ ] **End-to-End Encrypted WebDAV / S3 Sync**: Optional peer-to-peer or private cloud backup for multi-device syncing.
- [ ] **Raycast / Alfred Style Quick Actions**: Slash command workflow triggerable directly from the scratchpad (`/clean`, `/curl2python`, `/json2ts`).
